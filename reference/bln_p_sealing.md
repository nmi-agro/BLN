# Calculate and evaluate the soil sealing risk

This function calculates the risks of soil sealing.

## Usage

``` r
bln_p_sealing(B_LU_BRP, A_SOM_LOI, A_CLAY_MI)
```

## Arguments

- B_LU_BRP:

  (numeric) The crop code

- A_SOM_LOI:

  (numeric) The organic matter content of soil (%)

- A_CLAY_MI:

  (numeric) The clay content of the soil (%)

## Value

The risk of soil sealing as affected by the soil organic matter and clay
content. A numeric value.
