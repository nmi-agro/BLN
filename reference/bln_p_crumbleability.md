# Calculate and evaluate the crumbleability in view of the soils production function

This function calculates the crumbleability.

## Usage

``` r
bln_p_crumbleability(B_LU_BRP, A_SOM_LOI, A_CLAY_MI, A_PH_CC)
```

## Arguments

- B_LU_BRP:

  (numeric) The crop code from the BRP

- A_SOM_LOI:

  (numeric) The organic matter content of soil (%)

- A_CLAY_MI:

  (numeric) The clay content of the soil (%)

- A_PH_CC:

  (numeric) The pH of the soil, measured in 0.01M CaCl2

## Value

The crumbleability index of a soil, a measure for a physical soil
property. A numeric value.
