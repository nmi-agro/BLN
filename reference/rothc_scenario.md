# Function to prepare inputs for various scenarios with RothC

Function to prepare inputs for various scenarios with RothC

## Usage

``` r
rothc_scenario(B_LU_BRP, scen)
```

## Arguments

- B_LU_BRP:

  (numeric) value of the BRP crop code

- scen:

  (character) possible scenarios. Include BAU, CLT, BAUIMPR and ALL
