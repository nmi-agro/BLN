# RothC calculation motor

Set of differential equations to calculate the evolutotion of Soil
Organic Carbon using the RothC model.

## Usage

``` r
bln_rothc(time, y, parms)
```

## Arguments

- time:

  time to print output

- y:

  state variables to run RothC

- parms:

  parameters to run RothC, includes rate modifying functions and
  constants R1, abc, and d
